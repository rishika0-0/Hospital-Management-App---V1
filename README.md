# Hospital-Management-App---V1

A web-based Hospital Management System built using Flask, Jinja2, HTML, CSS, and Bootstrap, with SQLite as the database.

This system streamlines hospital operations by managing patients, doctors, appointments, and treatment records efficiently.

Key Features:

👨‍💼 Admin Panel: Manage doctors, patients, and appointments.

🩺 Doctor Dashboard: View assigned patients, update diagnosis and treatment details.

🧑‍🤝‍🧑 Patient Portal: Book appointments, view prescriptions, and track medical history.

📅 Smart Scheduling: Avoid appointment conflicts and maintain accurate records.

Tech Stack:

Backend: Flask (Python)

Frontend: Jinja2, HTML, CSS, Bootstrap

Database: SQLite
